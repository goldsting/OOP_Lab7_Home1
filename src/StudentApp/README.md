# Student Project

## Описание проекта
Консольное приложение на C# для управления информацией о студентах.

## Функциональность
- Создание студентов с ID, именем, группой и средним баллом
- Отображение информации о студенте
- Проверка, является ли студент отличником (средний балл >= 4.5)
- Обновление среднего балла студента

## Технологии
- .NET
- C#
